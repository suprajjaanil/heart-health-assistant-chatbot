## Overview

Heart Health Assistant Chatbot is an educational healthcare-support application that combines machine learning, ECG image classification, and conversational AI in an interactive interface.

The application includes a heart disease risk prediction model, an ECG image classification feature, and a chatbot powered by Google's Gemini API. The project explores how machine learning and conversational AI can be integrated into a single application for heart-health awareness.

## Features

- **Heart Disease Risk Prediction:** Uses a trained machine learning model to estimate risk from supported input features.
- **ECG Image Classification:** Accepts ECG image uploads and returns a predicted positive or negative class using an integrated image-classification model.
- **AI-Powered Chatbot:** Uses Google's Gemini API to answer general heart-health questions.
- **Interactive Interface:** Built with Gradio for user interaction.
- **Data Exploration:** Includes a Jupyter Notebook for exploring and understanding the data used in the project.

## Datasets and Resources

### GenECG — ECG Image Dataset

The ECG image component uses images sourced from the [GenECG dataset on Hugging Face](https://huggingface.co/datasets/akshithamuthyalampally/GenECG).

The project uses images from the `Dataset_A_ECGs_without_imperfections` subset for experimentation with ECG image classification.

**Dataset attribution:** Akshithamuthyalampally, GenECG, Hugging Face.

The dataset is derived from PTB-XL. Please refer to the original dataset documentation and license before redistributing dataset images or using them for other purposes.

## Getting Started

### Prerequisites

- Python
- A Google Gemini API key for chatbot functionality

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/suprajaani1/heart-health-assistant-chatbot.git
   cd heart-health-assistant-chatbot
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Configure the `GEMINI_API_KEY` environment variable with your own Gemini API key. Never commit API keys or tokens to GitHub.

4. Run the application:

   ```bash
   python app.py
   ```

5. Open the local URL displayed in the terminal.
